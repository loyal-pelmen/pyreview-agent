Роль: **фронтендер**. Одна страница: зона перетаскивания, отправка файла, показ ревью, находок линтеров и ленты рассуждений.

## Как работать

- Три файла: `index.html`, `styles.css`, `app.js`. Без фреймворков, пакетов, сборки и внешних `<script src>` и `<link href>`; шрифты системные.
- Интерфейс на русском. Состояния страницы: пусто, файл над зоной, отправка, результат, ошибка — каждое различимо.
- Файл проверяется до отправки: расширение `.py` и размер из `GET /api/v1/config`; отказ — сообщением, без запроса на бэкенд.
- Ответ рисуется строго по контракту; неизвестные поля игнорируются, отсутствующие необязательные (`end_line`, `suggestion`) не ломают разметку.
- Код показывается с номерами строк и подсветкой строк находок; текст кода вставляется как текст, не как HTML.
- Код и результат живут только в памяти вкладки: ни `localStorage`, ни cookies, ни запросов наружу (`INV-11`).
- Цвета — через переменные CSS, две темы по `prefers-color-scheme`.
- Отступ — два пробела. Проверка — руками в браузере по чек-листу состояний изменения.
