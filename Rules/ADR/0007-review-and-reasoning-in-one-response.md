# 0007 — Ревью и цепочка рассуждений одним ответом

Тип: решение
Статус: принято, 29.10.2026

## Контекст

Страница должна показать не только находки, но и ход мысли агента. У GigaChat на ключе проекта модели с отдельным «скрытым» рассуждением нет (`openspec/notes/gigachat.md`), зато у агента на Deep Agents есть след: текст модели между ходами, вызовы инструментов с аргументами и их результаты. Анализ длится до пары минут, и возникает выбор между одним ответом по завершении и потоковой отдачей шагов.

## Решение

Один синхронный ответ `200` по завершении анализа. Цепочка рассуждений — список шагов `reasoning[]`, собранный из следа агента: `thought` — текст модели между вызовами, `tool_call` — имя инструмента и аргументы, `tool_result` — результат, обрезанный до порога, `conclusion` — поле рассуждения из структурированного ответа модели. У каждого шага порядковый номер и время от начала в миллисекундах. Ревью — структурированный ответ модели через `with_structured_output` по модели pydantic: итог, вердикт, находки со строками. Находки линтеров идут отдельным списком `lint[]` из результатов инструментов, а не из пересказа модели. Пока идёт анализ, страница показывает состояние ожидания с именем файла.

## Альтернативы

- **Потоковая отдача шагов через SSE** — отложено, не отклонено: даёт живую ленту, но требует второго контракта, обработки обрыва и буферизации на прокси. Добавляется отдельным изменением поверх того же списка шагов после MVP.
- **Только итоговое ревью без следа** — отклонено: цепочка рассуждений — требование флоу.
- **Просить модель писать рассуждение прозой в одном поле** — отклонено как единственный источник: проза не привязана к реальным вызовам инструментов и не проверяема; поле `conclusion` остаётся дополнением к следу.
- **Находки линтеров только через модель** — отклонено: модель может опустить часть; список из инструментов полный и детерминированный.

## Последствия

- Коллектор шагов — отдельный объект, который middleware или callback агента пополняет по ходу; он же считает вызовы инструментов для `limits.max_tool_calls`.
- Таймаут анализа возвращает `504`, а не частичный ответ: без потоковой отдачи частичный след некуда показать. С появлением SSE это пересматривается.
- Страница получает всё сразу и рисует без состояния соединения; переход на SSE затронет только `app.js` и новый эндпоинт.
- Тест агента — фейк модели с заданной последовательностью вызовов: след предсказуем и сравнивается с ожидаемым списком шагов.
