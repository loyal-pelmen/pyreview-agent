# 0002 — Deep Agents как каркас, GigaChat как модель

Тип: решение
Статус: принято, 29.10.2026; корень бэкенда файлов — временный каталог, запись 0006

## Контекст

Нужен агент, который сам решает, какие файлы читать, когда звать линтеры и что писать в обзор. Это цикл «модель → инструмент → модель» с планированием и чтением файлов, и писать его руками поверх голого API модели — значит повторить то, что уже есть в каркасах. Модель задана заранее — GigaChat: у неё есть вызов функций, но один вызов за ход и свой OAuth с российской цепочкой сертификатов (`openspec/notes/gigachat.md`).

## Решение

Каркас — Deep Agents (`create_deep_agent`) поверх LangGraph: даёт планирование, файловые инструменты над бэкендом, субагентов и middleware без своего кода. Модель — `langchain_gigachat.GigaChat`, передаётся объектом, а не строкой провайдера. Бэкенд файлов — `FilesystemBackend` с корнем в checkout головы PR и allowlist инструментов только на чтение: `read_file`, `ls`, `glob`, `grep`. Свои инструменты — GitHub и линтеры — передаются через `tools=`. Ограничение «один вызов инструмента за ход» закреплено промптом и middleware, которое оставляет первый вызов и возвращает модели остальные как отказ.

Промпты, имена инструментов и форма находки живут в зоне `review`; зоны `github` и `linters` о модели не знают.

## Альтернативы

- **Свой цикл на `gigachat` SDK** — отклонено: планирование, чтение файлов и ограничение контекста пришлось бы писать и поддерживать самим.
- **LangGraph напрямую без Deep Agents** — отклонено: больше кода графа ради того же результата; Deep Agents и есть готовый граф под эту задачу.
- **Другая модель с параллельными вызовами** — вне решения: модель задана условием проекта. Замена модели — замена одного объекта в `ioc.py`.
- **Бэкенд `StateBackend` с диффом в состоянии** — отклонено: агент не смог бы заглянуть в код вокруг диффа, а именно это отличает ревью от чтения патча.

## Последствия

- Код агента тонкий: промпт, инструменты, сборка в `ioc.py`. Поведение правится промптом и набором инструментов, а не графом.
- Зависимость от скорости выхода Deep Agents: API библиотеки сверяется через context7 перед каждой задачей, версии пинятся в `uv.lock`.
- Тест агента — фейк модели, отдающий заданную последовательность вызовов инструментов; живой GigaChat только под меткой `integration`.
- Субагент на новый вид проверки — точка расширения без правки главного промпта.
