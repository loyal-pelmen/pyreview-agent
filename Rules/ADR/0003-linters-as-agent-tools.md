# 0003 — Линтеры — инструменты агента над checkout PR

Тип: решение
Статус: принято, 29.10.2026; checkout заменён временным каталогом записью 0006

## Контекст

Требование проекта — вызов линтеров через tool calling: модель сама решает, когда позвать `ruff` и `ty`, и читает их вывод. Линтер работает над файлами на диске, а конфигурацию берёт из проверяемого репозитория. Дать модели оболочку нельзя: текст от модели исполняться не должен.

## Решение

Два инструмента, `run_ruff` и `run_ty`, за одним портом `Linter`. Аргумент — список путей относительно checkout; инструмент проверяет, что каждый путь лежит внутри checkout и входит в изменённые файлы PR, иначе отвечает отказом. Линтер запускается подпроцессом с фиксированными аргументами и таймаутом из настройки, вывод разбирается в находки `файл:строка:код:сообщение` и обрезается до порога. Checkout — `git clone --depth 1` головы PR во временный каталог, удаляемый по завершении запуска.

Главный агент получает линтеры как инструменты, а не как шаг перед моделью: результат линтера — часть рассуждения, модель отсеивает шум и не дублирует находки ruff своими.

## Альтернативы

- **Запуск линтеров до модели и подмешивание вывода в промпт** — отклонено: нарушает требование о tool calling и забивает контекст выводом, который модели не нужен.
- **Инструмент `execute` Deep Agents с `LocalShellBackend`** — отклонено: это оболочка, и текст от модели станет командой (`INV-10`).
- **Линтеры через GitHub Actions проверяемого репозитория** — отклонено: у чужого репозитория может не быть CI, а агент должен работать с любым.

## Последствия

- У модели два узких инструмента вместо оболочки; новый линтер — новый адаптер порта, а не новая команда.
- `ruff` и `ty` ставятся в окружение агента и запускаются из него; версия линтера в проверяемом репозитории не учитывается.
- Вывод линтера ограничен порогом: большой PR с тысячей замечаний даёт обрезанный вывод и пометку в обзоре.
- Таймаут линтера — настройка; линтер, не уложившийся в него, останавливается, а инструмент сообщает об этом модели.
