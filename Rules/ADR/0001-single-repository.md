# 0001 — Один репозиторий без сабмодулей

Тип: решение
Статус: принято, 29.10.2026

## Контекст

Контекстное пространство — `AGENTS.md`, `Rules/`, `openspec/`, скиллы и хуки — переносится из проекта расписания МТУСИ, где код, фронт и правила живут в четырёх репозиториях с сабмодулями. У агента ревью PR одна кодовая база на Python, фронта нет, контура нет, а работает над ним один человек.

## Решение

Один репозиторий. `src/pyreview/` — код, `tests/` — тесты, `Rules/` — правила, требования и журнал решений, `openspec/` — контекст и изменения. Раскладка документов та же, что в эталоне, но без `make sync`, `.gitmodules` и указателей на подрепозитории.

## Альтернативы

- **Mono с сабмодулями `Rules` и `Backend`, как в эталоне** — отклонено: два репозитория ради одного пакета удваивают число коммитов и пушей, а разделять историю правил и кода некому.
- **Без `Rules/`, всё в `AGENTS.md`** — отклонено: `AGENTS.md` фиксирует наличие документов, а не нормы; нормы без своего файла расползаются по промптам.

## Последствия

- Задача не пересекает границу репозитория по определению; группировка задач в `tasks.md` идёт по зонам, а не по репозиториям.
- Ссылки на записи в PR — относительные пути `Rules/ADR/NNNN-….md` этого же репозитория.
- Если появится второй пакет — отдельный сервис или фронт, — решение пересматривается новой записью.
