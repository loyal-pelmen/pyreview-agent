# 0008 — Модель и пределы в `config.json`, секреты в окружении

Тип: решение
Статус: принято, 29.10.2026

## Контекст

Владелец хочет менять модель без правки кода через JSON-файл конфигурации. При этом ключ GigaChat — секрет, и в файле, который правят руками и могут закоммитить, ему не место. Помимо модели есть пределы — размер файла, число находок, таймауты — и флаги линтеров, которые логично держать рядом.

## Решение

`config.json` в корне репозитория, путь переопределяется `CONFIG_PATH`. Три секции: `llm` — `provider`, `model`, `temperature`, `max_tokens`, `timeout_seconds`; `linters` — `ruff`, `ty`, `timeout_seconds`; `limits` — `max_file_bytes`, `max_findings`, `max_tool_calls`, `analysis_timeout_seconds`. Файл читается один раз при старте в модель pydantic `AppConfig` с `extra="forbid"`; неверный файл роняет старт с именем поля. Секреты — только переменные окружения: `GIGACHAT_CREDENTIALS`, `GIGACHAT_SCOPE`, `GIGACHAT_CA_BUNDLE_FILE`. `llm.provider` в MVP принимает одно значение `gigachat`; адаптер выбирается в `ioc.py` по этому полю, чтобы второй провайдер добавлялся адаптером, а не правкой сборки. `GET /api/v1/config` отдаёт модель, включённые линтеры и пределы.

## Альтернативы

- **Всё в переменных окружения** — отклонено: владелец просил файл, а дюжина переменных с вложенной структурой читается хуже JSON.
- **Секреты тоже в `config.json`** — отклонено: файл в репозитории, и одна случайная правка утекает ключом (`INV-02`).
- **YAML или TOML** — отклонено: JSON назван владельцем, и ему хватает стандартной библиотеки.
- **Горячая перезагрузка конфига** — отклонено: бэкенд без состояния перезапускается за секунду, а перезагрузка на лету добавляет гонки между запросами.

## Последствия

- Имя модели и пороги нигде в коде не встречаются: тесты подставляют свой `AppConfig`.
- Смена модели — правка строки и перезапуск; проверка, что новая модель держит вызов инструментов, — на владельце или на наборе `integration`.
- Новый провайдер — адаптер и значение `provider`; это точка расширения в `RULES.md`.
- `config.json` в репозитории — рабочий пример со значениями по умолчанию, а не шаблон с пустыми полями.
