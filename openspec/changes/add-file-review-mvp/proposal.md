## Why

Решения по продукту приняты (записи 0002, 0003, 0006–0008), контракт API записан, но кода флоу нет: файл некуда отправить и ревью получить нельзя. Изменение собирает MVP целиком — шаги 1–5 `openspec/notes/mvp-plan.md` — одним проходом против общих контрактов, чтобы закрыть блоки приёмки 1–6 `Rules/REQUIREMENTS.md`. Классификация — фича, [запись 0009](../../../Rules/ADR/0009-file-review-mvp.md).

## What Changes

- Приём одного файла `.py` в `POST /api/v1/review` с проверкой расширения, размера и UTF-8 до линтеров и модели; временный каталог на время запроса.
- Адаптеры `ruff` и `ty` с таймаутом и разбором вывода в общую форму находки; инструменты агента `run_ruff` и `run_ty`.
- Агент Deep Agents на GigaChat: промпт на русском, один вызов инструмента за ход, предел вызовов и времени, структурированный ответ, проверка строк находок, цепочка рассуждений из следа.
- `GET /api/v1/config`, `GET /healthz`, отдача страницы статикой, конверт ошибки.
- Страница `frontend/`: зона перетаскивания, проверки до отправки, состояния, код с подсветкой строк, находки, лента рассуждений, режим `?demo`.
- `config.json` дополнен ключами `linters.ruff_select`, `limits.max_prompt_chars`, `limits.max_tool_output_chars` (`FR-C-01`).

Поведение, завязанное на вывод линтеров и форму ответа модели, проверяется на фикстурах в `tests/fixtures/` и фейке модели, а не по документации.

Части: shared, linters, analysis, entrypoints, frontend, `config.json`.

## Capabilities

### New Capabilities

- `file-intake`: приём и проверка файла — `FR-U-01`–`FR-U-06`, `NFR-02`, `NFR-05`; блоки 1, 6.
- `lint-tools`: `run_ruff` и `run_ty` как инструменты агента — `FR-L-01`–`FR-L-05`, `NFR-06`; блок 2.
- `code-analysis`: агент, находки, цепочка рассуждений, пределы — `FR-R-01`–`FR-R-05`, `NFR-01`, `NFR-04`, `NFR-06`; блоки 3, 6.
- `review-api`: эндпоинты, контракт ответа, ошибки, конфиг — `FR-V-01`, `FR-C-03`, `NFR-03`, `NFR-04`; блоки 4, 5, 6.
- `review-page`: состояния страницы и отрисовка — `FR-U-01`–`FR-U-03`, `FR-U-05`, `FR-V-02`–`FR-V-05`, `FR-V-07`; блоки 1, 4.
- `model-config`: `config.json` и секреты из окружения — `FR-C-01`–`FR-C-05`; блок 5.

### Modified Capabilities

Нет: действующих спецификаций в `openspec/specs/` ещё нет.

## Impact

- Код: `src/pyreview/` (зоны `analysis`, `linters`, `shared`, `entrypoints`), `frontend/`, `tests/`.
- Зависимости: `deepagents`, `langchain-gigachat`, FastAPI, `ruff` и `ty` из окружения бэкенда — уже в `pyproject.toml`.
- Внешние системы: GigaChat API с bundle сертификатов Минцифры (`openspec/notes/gigachat.md`).

## Non-goals

Всё из Out of scope `openspec/config.yaml`: хранение файлов и истории, несколько файлов и GitHub, правка кода за пользователя, фреймворки и CDN на фронте, второй провайдер, оболочка и запись файлов у модели. Кроме того — потоковая лента (запись 0007), `FR-V-06`, `FR-R-06`, субагенты и шаг 6 плана: прогон на наборе файлов и настройка промпта.
