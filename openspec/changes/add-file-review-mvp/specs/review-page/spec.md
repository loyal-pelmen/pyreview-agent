## Purpose

Страница, на которую человек перетаскивает файл `.py` и где читает ревью, находки линтеров и ленту рассуждений; каждое состояние различимо, данные живут только в памяти вкладки.

## ADDED Requirements

### Requirement: Состояния страницы
Страница MUST иметь различимые состояния: пусто — зона перетаскивания и кнопка выбора файла; файл над зоной — зона подсвечена; отправка — имя файла и индикатор ожидания, повторная отправка недоступна; результат — код, ревью, линтеры, лента; ошибка — сообщение из конверта и возможность отправить новый файл.

Трассировка: `FR-U-01`, `FR-U-05`, `FR-V-05`; блоки приёмки 1, 4.

#### Scenario: Файл над зоной
- **WHEN** пользователь тащит файл над зоной
- **THEN** зона подсвечена, после ухода курсора подсветка снимается

#### Scenario: Отправка
- **WHEN** пользователь бросил `app.py` в зону или выбрал его в диалоге
- **THEN** страница отправляет `POST /api/v1/review` с полем `file` и показывает имя файла и ожидание

#### Scenario: Ошибка бэкенда
- **WHEN** бэкенд ответил `502` с конвертом ошибки
- **THEN** страница показывает `error.message` без сырого JSON, и новый файл можно отправить без перезагрузки

### Requirement: Проверка до отправки
Страница MUST отклонять файл не `.py` и файл больше `limits.max_file_bytes` из `GET /api/v1/config` до отправки, с сообщением и без запроса к `/api/v1/review`.

Трассировка: `FR-U-02`, `FR-U-03`; блок приёмки 1.

#### Scenario: Файл `.txt`
- **WHEN** пользователь бросил `notes.txt`
- **THEN** страница показывает сообщение о том, что нужен `.py`, запрос не уходит

#### Scenario: Большой файл
- **WHEN** пользователь бросил `.py` больше предела
- **THEN** страница показывает сообщение о размере, запрос не уходит

### Requirement: Отрисовка результата
Страница MUST показывать итог и вердикт, находки ревью с серьёзностью и строкой, находки линтеров по инструментам, код с номерами строк и подсветкой строк находок, сворачиваемую ленту рассуждений с различимыми типами шагов и имя модели в подвале; код вставляется как текст, а не как HTML.

Трассировка: `FR-V-02`, `FR-V-03`, `FR-V-04`, `FR-C-03`; блок приёмки 4.

#### Scenario: Клик по находке
- **WHEN** пользователь кликает находку на строке 42
- **THEN** код прокручивается к строке 42, строка подсвечена

#### Scenario: Код с разметкой
- **WHEN** в файле есть строка `s = "<script>alert(1)</script>"`
- **THEN** строка показана текстом, скрипт не исполняется

#### Scenario: Необязательные поля отсутствуют
- **WHEN** у находки `end_line` и `suggestion` равны `null`
- **THEN** находка показана без них, разметка не ломается

### Requirement: Тема и хранение
Страница MUST следовать системной светлой или тёмной теме и не хранить код и результат вне памяти вкладки: без `localStorage`, cookies и запросов наружу; режим `?demo` рисует результат из примера ответа `frontend/fixtures/sample-response.json` без запроса к `/api/v1/review`.

Трассировка: `FR-V-07`, `INV-11`; блок приёмки 4.

#### Scenario: Тёмная тема
- **WHEN** в системе включена тёмная тема
- **THEN** страница показана в тёмной палитре

#### Scenario: Демо без бэкенда
- **WHEN** открыт `/?demo`
- **THEN** страница показывает результат из примера ответа, запрос к `/api/v1/review` не уходит
