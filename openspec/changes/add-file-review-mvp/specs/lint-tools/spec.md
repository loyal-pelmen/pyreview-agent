## Purpose

Инструменты агента `run_ruff` и `run_ty`: агент сам запускает линтеры над присланным файлом, читает их вывод в общей форме, а ответ содержит полный список находок линтеров.

## ADDED Requirements

### Requirement: Инструменты `run_ruff` и `run_ty`
Агент MUST получать инструменты `run_ruff` и `run_ty` с моделью аргументов `{path: str}` — имя файла внутри каталога запроса. Инструмент возвращает строку: по строке на находку в форме `строка:столбец код сообщение` или сообщение, что находок нет; длина ответа не больше `limits.max_tool_output_chars`, обрезка помечается в тексте.

Трассировка: `FR-L-01`, `FR-L-02`, `NFR-06`; блок приёмки 2.

#### Scenario: `ruff` нашёл неиспользуемый импорт
- **WHEN** агент вызывает `run_ruff` с `{"path": "app.py"}` для файла с `import os` без использования
- **THEN** инструмент возвращает строку с `F401` и номером строки импорта

#### Scenario: `ty` нашёл ошибку типа
- **WHEN** агент вызывает `run_ty` для файла с вызовом функции с аргументом неверного типа
- **THEN** инструмент возвращает строку с кодом правила `ty` и номером строки вызова

#### Scenario: Длинный вывод обрезан
- **WHEN** вывод линтера длиннее `limits.max_tool_output_chars`
- **THEN** агент получает строку не длиннее предела с пометкой об обрезке, а шаг `tool_result` в `reasoning` помечен `truncated: true`

#### Scenario: Путь вне каталога запроса
- **WHEN** агент вызывает инструмент с `{"path": "../etc/passwd"}` или с именем чужого файла
- **THEN** линтер не запускается, инструмент возвращает агенту сообщение об отказе, запрос продолжается

#### Scenario: Неверный аргумент
- **WHEN** агент вызывает инструмент без `path` или с аргументом не той формы
- **THEN** агент получает сообщение об ошибке аргумента, запрос не падает

### Requirement: Таймаут линтера
Инструмент MUST останавливать линтер, не завершившийся за `linters.timeout_seconds`, и возвращать агенту сообщение об этом вместо находок.

Трассировка: `FR-L-03`, `INV-09`; блок приёмки 2.

#### Scenario: Линтер не уложился в таймаут
- **WHEN** `ty` работает дольше `linters.timeout_seconds`
- **THEN** процесс остановлен, агент получает сообщение о таймауте, ответ `200` строится без находок `ty`

### Requirement: Выключенный линтер не предлагается
Линтер, выключенный в `config.json`, MUST не запускаться и не попадать в список инструментов агента.

Трассировка: `FR-L-04`; блок приёмки 2.

#### Scenario: `ty` выключен
- **WHEN** `linters.ty = false`
- **THEN** у агента нет инструмента `run_ty`, в `lint` нет записей `tool = "ty"`, `GET /api/v1/config` не перечисляет `ty`

### Requirement: Находки линтеров в ответе
Ответ MUST содержать в `lint` полный список находок включённых линтеров независимо от того, вызвал ли их агент и упомянул ли в ревью.

Трассировка: `FR-L-05`; блок приёмки 2.

#### Scenario: Модель не вызвала линтер
- **WHEN** агент закончил разбор, не вызвав `run_ty`
- **THEN** `lint` всё равно содержит находки `ty` для файла
