## Как работать

- Зоны `analysis` и `linters`, платформа `shared`, точки входа `entrypoints`; внутри зоны `domain/`, `application/`, `infrastructure/`. Зоны не импортируют инфраструктуру друг друга, связь — через порты в `application/`.
- Стрелки указывают внутрь: `domain/` не импортирует инфраструктуру, `application/` зависит от портов, адаптеры подключаются в `ioc.py`.
- Инструмент агента — тонкая функция над портом: проверяет аргумент, зовёт порт, обрезает ответ до порога, возвращает строку.
- Модель получает только структурированные инструменты: ни оболочки, ни HTTP, ни записи в каталог.
- Временный каталог создаётся на запрос и удаляется в `finally`; содержимое файла в лог не пишется.
- Ответ собирается целиком по контракту и отдаётся одним JSON; ошибка — конвертом с кодом.
- Модель и пределы берутся из `AppConfig`, не из констант; секреты — из окружения.
- API Deep Agents, langchain-gigachat и FastAPI сверяются через context7 перед правкой.
- Перед коммитом — `make lint` и `make test`.
